# 🛒 Ecommerce Cart Page

A clean, modern, and responsive **E-commerce Shopping Cart interface** built with **HTML and Tailwind CSS**.

The project focuses on creating a smooth shopping-cart experience with a structured layout, responsive design, product controls, and a detailed order summary.

---


## 📌 About The Project

This project is a front-end implementation of an e-commerce cart page.

It includes the main elements users would expect when reviewing their shopping cart before checkout:

* 🛍️ Product cart items
* ➕➖ Quantity controls
* 💰 Order and price summary
* 🚚 Shipping and tax information
* 🔎 Product search
* 👤 Account and cart navigation
* 💳 Payment method section
* 📱 Responsive layout

The interface was designed to remain simple, clean, and easy to navigate across different screen sizes.

## 🧩 Main Sections

### Header

Contains the website branding, navigation links, categories, search functionality, and user/cart icons.

### Cart

Displays the products currently added to the shopping cart, including product information, price, quantity, and removal controls.

### Order Summary

Provides a quick overview of the purchase, including subtotal, shipping, tax, and the final amount.

### Footer

Contains company information, useful links, shopping/support sections, payment methods, and social media icons.
